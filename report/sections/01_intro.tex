\section{Introduction and Project Overview}
\label{sec:intro}

\subsection{Background and Objectives}
Checkers (known internationally as \emph{English draughts}) is one of the foundational benchmarks in computer science and game-playing research---from Arthur Samuel's pioneering 1959 self-learning program \cite{samuel1959} to Jonathan Schaeffer et al.'s 2007 proof in \emph{Science} that English checkers is a weakly solved draw across $\approx 5\times 10^{20}$ board states \cite{schaeffer2007}. In the Computer Architecture Lab (\textbf{CO2008}) assignment at Ho Chi Minh City University of Technology (HCMUT), students implement a complete English Checkers engine directly in \textbf{MARS 4.5 MIPS32 Assembly} \cite{vollmar2006}.

Building a non-trivial interactive game at the instruction-set level directly reinforces four core themes of modern computer organization \cite{patterson2020,hennessy2019}:
\begin{enumerate}
    \item \textbf{Low-level data modeling \& cache awareness:} Structuring the $8\times 8$ board (fitting inside a single 64-byte L1 cache line), move history, and 16\,KiB memory-mapped framebuffer (\code{0x10040000}) directly in flat MIPS32 virtual memory.
    \item \textbf{Bitwise arithmetic \& Chinook SWAR bitboards:} Replacing divisions and modulo operations with bit shifts (\code{sll}, \code{srl}), masks (\code{andi}), and involutive transforms---and deploying a full \textbf{hybrid 64-byte mailbox + 32-bit Chinook SWAR bitboard engine} \cite{schaeffer2007,warren2012,rapid_draughts} directly in production MIPS32 for mobility, forced capture, bidirectional move hints, and branchless SWAR \code{popcount}.
    \item \textbf{MIPS32 ABI \& pipeline discipline:} Organizing 2,451 assembly lines into 48 cleanly decoupled procedures (23 leaf, 25 non-leaf) across four source files with 100\% symmetric stack frames, zero ABI violations, and zero-stall load-use delay scheduling inside hot pixel and bitboard-packing loops.
    \item \textbf{Rigorous multi-tier verification:} Pairing a crash-proof \code{syscall 14} buffered stdin parser with \textbf{54 automated \code{pytest} tests}---including live MARS 4.5 \textbf{WCDF \code{Perft}(1--3)} tree verification (\code{7 / 49 / 302})---and a \textbf{4,000-query differential property-based fuzzer} \cite{mckeeman1998,hur2021}.
\end{enumerate}

\subsection{Delivered Scope Summary}
The CO2008 specification distinguishes a \emph{bare-minimum product} (Sections~1--2, capped at 9/10 marks or 8/10 for the Honors program) from \emph{Quality-of-Life (QoL)} and \emph{Advanced Ruleset} extensions (Section~3). Our submission fulfills 100\% of the core requirements and adds ten substantial runtime-configurable extensions via an interactive menu (entering \code{0} at the starting-square prompt), while preserving bit-exact compatibility with automated classic transcript fixtures through the MARS program argument \code{pa classic}.

\begin{keybox}{\faCheckCircle\hspace{0.45em}Executive Summary of Audited Deliverables \& Production v2.0 Upgrades}
\footnotesize
\begin{itemize}[topsep=1pt,itemsep=1.5pt]
    \item \textbf{Modular Hybrid MIPS32 Engine (v2.0):} 2,451 lines across 4 files (\code{defs.asm}, \code{main.asm}, \code{board\_io.asm}, \code{rules.asm}), assembling to \textbf{2,283 basic MIPS32 instructions} (9,132\,B \code{.text}), \textbf{8,192\,B} \code{.data}, and a strictly bounded \textbf{116\,B} call stack with \textbf{0 ABI/liveness violations}.
    \item \textbf{Full English Rules + Promotion Chain:} 12 pieces/side, Black moves first, instant promotion on rows 0/7, immediate backward chain-capture upon promotion (Spec Fig.~8), and win detection by both \emph{elimination} and \emph{complete blockade} (Spec Fig.~9).
    \item \textbf{Quality-of-Life \& Advanced Rules (14 Menu Items):} Dual-panel framed board with SWAR \code{popcount} piece counters and rule banner; $180^\circ$ Red rotation; player-relative numbering ($s' = 33 - s$); 11-code diagnostic errors; SWAR-accelerated legal move hints; standard-notation history (1,000 steps); two-phase mutual draw protocol; restart \& replay; \textbf{Dirty-Tile MARS Bitmap Display} (\code{0x10040000}); \textbf{Forced First Capture}; and \textbf{Flying Kings}.

    \item \textbf{Deployed Production Speedups (v1.0 $\to$ v2.0 on Live MARS 4.5):} \textbf{5.17$\times$} full-game speedup on Pretty+Hints (\textbf{23.79$\times$} net hint engine via Chinook Bidirectional SWAR Duality), \textbf{15.19$\times$} on Classic+Bitmap (\textbf{42.59$\times$} single dirty move via Dirty-Tile + LICM + 8-way unrolled solid tiles + 0-stall scheduling), \textbf{8.40$\times$} on \code{side\_has\_capture}, and \textbf{$-12.8\%$ to $-20.7\%$} across all five classic fixtures.
\end{itemize}
