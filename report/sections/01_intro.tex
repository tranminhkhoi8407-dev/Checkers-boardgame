\section{Assignment scope and work delivered}
\label{sec:intro}

\subsection{Assignment and acceptance criteria}
We built a two-player checkers game in MARS 4.5 assembly. Its interface is deliberately small: enter two square numbers, inspect the updated board, and pass the terminal to the other player. The difficult part is deciding when to pass control. Invalid input must leave the position unchanged; a capture may require another jump by the same piece; and reaching the back row can change the legal direction of that next jump.

We used the assignment's requirements to separate the base game from optional rules. The terminal must show the position each turn, Black starts, and the game must announce the winner when the other side runs out of pieces. Continuing an available capture chain is compulsory. Forcing the first capture, rotating the view and allowing flying kings are separate settings, not assumptions about the base game. The report follows these decisions from board layout through implementation to the recorded tests and the MARS demonstration.

\subsection{Delivered Scope Summary}
The CO2008 specification distinguishes a \emph{bare-minimum product} (Sections~1--2, capped at 9/10 marks or 8/10 for the Honors program) from \emph{Quality-of-Life (QoL)} and \emph{Advanced Ruleset} extensions (Section~3). Our submission fulfills 100\% of the core requirements and adds ten substantial runtime-configurable extensions via an interactive menu (entering \code{0} at the starting-square prompt), while preserving bit-exact compatibility with automated classic transcript fixtures through the MARS program argument \code{pa classic}.
